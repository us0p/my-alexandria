## Dangling Pointer
Pointers that no longer point to a valid object. Usually it happens when a memory value is cleared before it's used.
## Memory Leak
When a pointer value is not freed. Causes the program to becomes slow or crash.
## Last In First Out (LIFO)
It's a data structure in which values are stored and consumed in a specific order. As the name suggest, elements added at the end are always the first to be consumed.
