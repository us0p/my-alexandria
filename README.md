# My Alexandria - Goal
A place to store my notes and generate automatic revision flash cards.

This knowledge base tries to approach knowledge acquiring and retention using scientific methods for maximum utilization.
## Notes
Notes are going to follow the Zettelkasten and Generative Notes methods and
will be formatted using [Markdown](https://www.markdownguide.org/basic-syntax/).

We want notes that are **highly interconnected** and that each note is 
**atomic** and **small**.
### Note types
There are three types of notes in this library:
- **Concept notes**: Definitions of a concept
- **Practical notes**: Where and how to apply a concept in practice with 
examples. Good pratical notes are problem 
oriented e.g. "Handling duplicated requests".
- **Decision notes**: Why one concept was chosen over the other and the 
implications. This note is only created when you have to consider many 
options for a particular problem, when this decision might be faced again 
or when trade-offs matter.

- A **Practical Note** is always linked to a **Concept Note**.
- A **Decision Note** is always linked to a **Practical Note** and to a 
**Concept Note**.
## Flash Cards
Flash Cards are going to be automatic generated based on the notes on the **library** folder.

The `Properties` section of each file is going to be used by the flash card generation script to manage cards status.
